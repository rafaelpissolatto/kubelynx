## Agent skills

### Issue tracker

Issues live in GitHub Issues (`rafaelpissolatto/kubelynx`), via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five canonical labels, used as-is. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Team personas

When work is split across parallel agents, each one adopts a persona: a Lead (architecture, ADRs, plan docs, cross-cutting review) plus two Senior SREs with disjoint ownership (backend/telemetry vs. frontend/rendering). See `docs/agents/personas.md`.
